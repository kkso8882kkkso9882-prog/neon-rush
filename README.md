# NEON RUSH 🏎️💨

เกมออฟไลน์ 3 มิติสไตล์ไซเบอร์พังก์ — ขับยานฮือหลบสิ่งกีดขวางในเมืองนีออนไม่รู้จบ
สร้างด้วย React + Vite + three.js + Tailwind CSS

## เล่นอย่างไร

- `←` `→` หรือ `A` `D` — เปลี่ยนเลน
- `Space` — เริ่มเกม / เล่นต่อ
- `P` — หยุดชั่วคราว
- มือถือ: สไวป์ซ้าย-ขวา หรือกดปุ่มบนหน้าจอ
- หลบกำแพงสีชมพู เก็บลูกแก้วสีฟ้า (+15 แต้ม)
- สถิติสูงสุดบันทึกในเครื่อง (localStorage) — เล่นออฟไลน์ได้ 100%

## เริ่มต้น

```bash
bun install
bun run dev          # รันเว็บ
bun tsc -b --noEmit  # ตรวจ typecheck
```

## โครงสร้างหลัก

- `src/game/neonRush.ts` — เอนจินเกม three.js (ฉาก, ยาน, สิ่งกีดขวาง, เสียง)
- `src/pages/Play.tsx` — หน้าเล่นเกม `/play` พร้อม HUD และ overlay
- `src/pages/Landing.tsx` — หน้าแรกธีมไซน์เวฟ

เข้าเล่นได้ทันทีที่ `/play` — ไม่ต้องสมัครสมาชิก ไม่ต้องต่ออินเทอร์เน็ตระหว่างเล่น
